# Obsidian Luxe

Premium dark theme for Aite Commander.

Direction:

- deep graphite foundation
- cool steel and aqua interaction accents
- restrained plum and teal structure markers
- soft high-contrast text without harsh neon saturation

Contents:

- `theme.json`
- `qss/obsidian_luxe.qss`
- full required icon set in `icons/`

Install:

1. Open Settings in Aite Commander.
2. Import a theme package.
3. Select the packaged `.zip`.
4. Pick `Obsidian Luxe` in the theme selector.
