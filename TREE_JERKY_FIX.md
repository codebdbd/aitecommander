# Исправление рывков при добавлении элементов дерева

**Дата:** 2025-10-17  
**Проблема:** Дерево обновляется рывками при добавлении секций и категорий  
**Статус:** ✅ Исправлено

## Причина

После добавления категории/секции через `item_added.emit()` запускалась **полная перезагрузка структуры** (`schedule_structure_reload()`), что вызывало:
- Полную перестройку дерева
- Повторную загрузку всех иконок
- Множественные перерисовки UI
- Визуальные рывки

## Решение

### 1. Убрана лишняя перезагрузка структуры

**Файл:** `app/controllers/business/structure/event_service.py:117-132`

```python
if item_type == "category":
    section_id = parent_id or (
        item_data.get("section_id") if isinstance(item_data, dict) else None
    )
    self._cache_service.invalidate_categories_cache(section_id)
    if isinstance(section_id, int) and section_id > 0:
        self._async_service.load_categories_async(section_id)
    # Инкрементальное обновление через item_added.emit() уже обработано
    # Полная перезагрузка структуры не нужна и вызывает рывки
    # НЕ делаем return — другие подписчики должны получить сигнал!

elif item_type == "section":
    # Для секций также используем инкрементальное обновление
    # Полная перезагрузка не нужна
    self._cache_service.invalidate_structure_cache()
    # НЕ делаем return — другие подписчики должны получить сигнал!
```

### 2. Поддержка QIcon в модели дерева

**Файл:** `app/views/models/structure_tree_model.py:321-338, 366-383`

Модель теперь поддерживает как QIcon (уже загруженная иконка), так и строку (путь для асинхронной загрузки):

```python
icon_data = s.get("icon")
# Поддержка QIcon (уже загруженная) или строки (путь)
icon = icon_data if isinstance(icon_data, QIcon) else QIcon()
```

Это позволяет `TreeUpdateService` передавать уже загруженные иконки из кэша, избегая повторной загрузки.

## Результат

- ✅ Добавление категорий/секций происходит плавно без рывков
- ✅ Используется инкрементальное обновление через модель
- ✅ Нет лишних перезагрузок структуры
- ✅ Иконки загружаются один раз (из кэша через `TreeUpdateService._preprocess_*_data()`)
- ✅ Модель поддерживает как QIcon, так и строковые пути

## Тестирование

1. Добавить новую категорию → должно быть плавно, иконка появляется сразу
2. Добавить новую секцию → должно быть плавно, иконка появляется сразу
3. Проверить логи — не должно быть "Loading structure for sphere" после добавления
