## Ключевые требования

- Light / Dark / System темы.
- Desktop 1440: container 1280, margins 80, 12 columns, 24 gutter.
- Onest — основной шрифт; JetBrains Mono — только технические фрагменты.
- Реальные скриншоты приложения — главный визуальный материал.
- Никаких типичных blue-purple SaaS/AI градиентов, glassmorphism, neon glow и device mockups.
- Hero: 5/7, реальный UI справа.
- Секция “А потом оказывается…” — фиксированный brand/navy смысловой поворот.
- Frozen copy не меняется без отдельного согласования.
- WCAG 2.2 AA, Lighthouse 90+/95+/95+/95+ как целевые значения.
- Static/prerender implementation; тяжёлый SPA runtime не нужен.
- До production обязательны реальные download URL, domain и проверка metadata.
