# Aite Commander — описание возможностей и функций

**Версия**: 1.0.0 | **Платформа**: Windows (PyQt6) | **Python**: ≥ 3.12

---

## Обзор

Aite Commander — десктопное приложение для управления закладками и ссылками, построенное по принципу иерархической организации. Название и философия вдохновлены Total Commander, но вместо файловой системы используется 4-уровневая структура: **Сфера → Раздел → Категория → Ссылка**.

База данных — SQLite с WAL-режимом и memory-mapped I/O. Интерфейс построен на PyQt6.

---

## 1. Иерархическая структура данных

Четырёхуровневая модель организации:

| Уровень | Таблица | Описание |
|---------|---------|----------|
| **Сфера** | `sphere` | Верхний уровень группировки (AI, Работа, Учёба, Личное и др.) |
| **Раздел** | `section` | Подраздел внутри сферы |
| **Категория** | `category` | Категория внутри раздела |
| **Ссылка** | `link` | Конкретная ссылка внутри категории |

Все уровни поддерживают:
- CRUD-операции (создание, чтение, обновление, удаление)
- Порядок позиционирования (сортировка)
- Иконки для каждого элемента
- Каскадное удаление (при удалении родителя удаляются все вложенные элементы)

### Типы ссылок

| Тип | Описание |
|-----|----------|
| `web` | Веб-ссылка (URL) |
| `file` | Файл на диске |
| `folder` | Папка |
| `program` | Программа/приложение |
| `script` | Скрипт |

## 2. Управление ссылками

### CRUD и батч-операции
- Создание, редактирование, удаление ссылок
- Диалог создания/редактирования ссылки с полями: имя, URL, тип, аргументы, браузер, иконка
- Массовые операции: пакетное создание, обновление, удаление, перемещение (до 5000 элементов за раз)
- Уникальность: `UNIQUE(category_id, name, url, args)`

### Избранные и недавние
- Панель **Избранное** в верхней панели быстрого доступа
- Панель **Недавние** — ссылки, использованные в последнее время
- Переключение статуса «Избранное» одним кликом

### Поиск
- Полноценный текстовый поиск по имени, URL, заметкам и аргументам ссылок
- Дебаунс 300 мс для плавной работы

### Заметки
- Поле заметок для каждой ссылки
- Редактирование заметок через контекстное меню

## 3. Навигация и интерфейс

### Дерево структуры

- Ленивая загрузка иконок

### Таблица ссылок
- Табличный вид ссылок с колонками: Избранное, Имя, Последнее открытие, Заметки
- Кэш иконок (LRU, 500 записей)
- Drag & Drop для перемещения ссылок

### Верхняя панель
- Панель Избранного и Недавних
- Панель быстрого добавления

- Путь к текущему элементу
- Статус базы данных
- Количество ссылок

## 4. Управление базой данных

### DatabaseManager
- Потокобезопасное управление соединениями (thread-local)
- WAL journal mode для производительности
- NORMAL synchronous, 256 MB memory-mapped I/O
- Настраиваемый размер кэша через переменную окружения `APP_DB_CACHE_SIZE_KIB`
- Контекстный менеджер транзакций с автооткатом
- Проверка здоровья соединения (ping)
- Логирование времени выполнения всех операций

### Миграции
- 6 миграций: начальная схема, добавление `browser_key`, изменение уникального ограничения, индексы NOCASE, индексы производительности, индекс позиции избранного
- Автоматический запуск миграций при инициализации

### Резервное копирование
- Автоматическое создание резервных копий SQLite
- Настраиваемое максимальное количество копий
- Восстановление из резервной копии с проверкой целостности
- Фоновое создание/восстановление копий через воркеры

## 5. Импорт и экспорт

### Полный импорт/экспорт
- Экспорт всей структуры (Сферы → Разделы → Категории → Ссылки) вложенным JSON
- Импорт полной структуры с восстановлением иерархии

### Частичный импорт/экспорт
- Экспорт отдельного раздела или категории
- Поддержка пакетов `.zip` с иконками (StructureShareService)

### Импорт из браузеров
- Парсинг HTML-экспорта закладок из всех основных браузеров (Netscape формат)
- Извлечение ссылок с категориями
- Обработка base64-иконок
- Нормализация URL

### Профили браузеров
- Обнаружение профилей Chrome, Edge, Firefox
- Асинхронное сканирование профилей
- Постоянный кэш профилей
- Извлечение иконок из профилей браузеров

## 6. Отмена и повтор (Undo/Redo)

- Полный стек отмены для операций со структурой и ссылками
- Макрокоманды для группировки операций
- Команды: создание, обновление, удаление, пакетные операции ссылок
- Команды структуры: вставка разделов, вставка категорий
- UndoDispatcher — диспетчер результатов отмены/повтора (регионы инвалидации, уведомления об ошибках)

## 14. Производительность

- **WAL mode** — параллельное чтение/запись в SQLite
- **Memory-mapped I/O** (256 МБ) — быстрый доступ к данным
- **LRU-кэши** — для иконок, QSS, тем
- **Ленивая загрузка** — иконки загружаются по мере необходимости
- **Фоновые воркеры** — все тяжёлые операции в фоновом потоке
- **Дебаунс поиска** — 300 мс
- **Кэширование структуры** — 5 минут TTL (cachetools)
- **Потокобезопасные соединения** — thread-local management

---

## 15. Архитектура

- **MVC/MVP** с паттерном Facade
- **Слой сервисов** — изоляция бизнес-логики от UI
- **Слой бизнес-контроллеров** — StructureBusinessLogic, LinksBusinessLogic
- **UI-контроллеры** — ActionController, MenuController, ThemeController, TopPanelsController и др.
- **Модульность** — чёткое разделение на controllers, models, views, services, core
- **Result[T] тип** — обработка ошибок со статусами SUCCESS/FAILURE/PARTIAL
- **UnitOfWork** — декоратор транзакций для методов сервисов

6. **Работа**: основной цикл Qt
7. **Завершение**: грамотное закрытие с приоритетными обработчиками
