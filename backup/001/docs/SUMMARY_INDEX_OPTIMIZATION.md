## 🎓 Технические особенности

### Partial Indexes (экономия памяти)
```sql
-- Индексируем только избранное (15 строк вместо 3837)
CREATE INDEX idx_link_is_favorite 
ON link(is_favorite) 
WHERE is_favorite = 1;
```

### Covering Indexes (нет обращения к таблице)
```sql
-- Индекс покрывает весь запрос
CREATE INDEX idx_link_category_position 
ON link(category_id, position);
```

### DESC для оптимизации сортировки
```sql
-- Направление сортировки в индексе
CREATE INDEX idx_link_last_used 
ON link(last_used DESC) 
WHERE last_used IS NOT NULL;
```
