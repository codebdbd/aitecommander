## ✅ Решение

Добавлена отсутствующая функция `_resolve_structure_loader` в `app/controllers/system/window_setup/__init__.py`.

### Реализация

```python
def _resolve_structure_loader(structure_business: Any) -> Callable[[], None]:
    """Создает функцию-загрузчик структуры из structure_business.
    
    Args:
        structure_business: Объект бизнес-логики структуры
        
    Returns:
        Функция без параметров для перезагрузки структуры
        
    Raises:
        ValueError: Если нет подходящего метода загрузки
    """
    # Приоритет: async > sync
    if hasattr(structure_business, 'load_structure_async') and callable(
        structure_business.load_structure_async
    ):
        logger.debug("Using load_structure_async for structure reload")
        return structure_business.load_structure_async
    
    if hasattr(structure_business, 'load_structure') and callable(
        structure_business.load_structure
    ):
        logger.debug("Using load_structure (sync) for structure reload")
        return structure_business.load_structure
    
    raise ValueError(
        "StructureBusinessLogic must provide load_structure_async or load_structure method"
    )
```

### Логика

1. **Приоритет async**: Сначала проверяется наличие `load_structure_async()`
2. **Fallback на sync**: Если async нет, используется `load_structure()`
3. **Валидация**: Если оба отсутствуют - ValueError

## ✅ Вторая проблема: Не работает поиск (ИСПРАВЛЕНО)

### 🔴 Проблема

В логах ошибка при поиске:

```python
TypeError: decorated slot has no signature compatible with TaskSignals.finished[object]
```

**Где проявляется:**
- При вводе текста в строку поиска
- При загрузке ссылок для категории
- При подсчете избранного

**Trace:**
```
File "links_business.py", line 165, in search_links
    run_db(..., on_finished=self._on_search_finished, ...)
File "api.py", line 136, in run_db
    task.signals.finished.connect(on_finished)
TypeError: decorated slot has no signature compatible with TaskSignals.finished[object]
```

### ✅ Причина

Сигнал `TaskSignals.finished` передает тип `object`, но декораторы `@pyqtSlot` были неправильными:

**Было:**
```python
@pyqtSlot(list)  # ❌ Неправильно!
def _on_search_finished(self, search_results: List[Dict]):
    self.search_results_ready.emit(search_results)

@pyqtSlot(list, int, int)  # ❌ Неправильно!
def _on_links_loaded(self, links: List[Dict], category_id: int, task_id: int):
    ...

@pyqtSlot(int, list, object)  # ❌ Неправильно!
def _on_favorites_counted(self, fav_count: int, links: List[Dict], link):
    ...
```

### ✅ Решение

Исправлены декораторы в `app/controllers/business/links_business.py`:

**Стало:**
```python
@pyqtSlot(object)  # ✅ Правильно!
def _on_search_finished(self, search_results: List[Dict]):
    self.search_results_ready.emit(search_results or [])

@pyqtSlot(object, int, int)  # ✅ Правильно!
def _on_links_loaded(self, links: List[Dict], category_id: int, task_id: int):
    with self._tasks_lock:
        if task_id in self.pending_tasks:
            del self.pending_tasks[task_id]
            self.links_loaded.emit(links or [], category_id, task_id)

@pyqtSlot(int, object, object)  # ✅ Правильно!
def _on_favorites_counted(self, fav_count: int, links: List[Dict], link):
    self.favorites_counted.emit(fav_count, links or [], link)
```

### 📝 Изменения

1. **Замена `list` на `object`** в декораторах `@pyqtSlot`
2. **Добавлена защита `or []`** для предотвращения None

### 📝 Почему `object` а не `list`?

**Причина:** Сигнал `TaskSignals.finished` определен как:

```python
# в app/utils/db/api.py
class TaskSignals(QObject):
    finished = pyqtSignal(object)  # ← Именно object!
    error = pyqtSignal(Exception)
    progress = pyqtSignal(float, str)
```

При подключении слота Qt проверяет **совместимость сигнатур**:
- Сигнал передает `object`
- Слот должен принимать `object` (или более общий тип)
- `list` → **несовместимо** → `TypeError` ❌
