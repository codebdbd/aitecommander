# Руководство пользователя Aite Commander

**Aite Commander** — это десктопное приложение для организации и быстрого запуска закладок, локальных файлов, папок, программ и скриптов в операционной системе Windows. Приложение объединяет эргономику классических двухпанельных менеджеров (Total Commander / Far Manager) с современной 4-уровневой иерархической моделью данных.

Данное руководство содержит полное описание всех возможностей программы, сценариев её настройки и повседневного использования.

## 1. Введение и концепция 4-уровневой структуры

Главная проблема традиционных браузерных закладок и ярлыков на рабочем столе — их неизбежное превращение в хаос при росте количества ссылок. В браузере сложно хранить локальные файлы и скрипты, а ярлыки Windows засоряют экран и не поддаются удобной фильтрации.

Aite Commander решает эту задачу с помощью четкой 4-уровневой модели данных:

```
[ СФЕРА (Sphere) ]
       │
       ▼
[ РАЗДЕЛ (Section) ]
       │
       ▼
[ КАТЕГОРИЯ (Category) ]
       │
       ▼
[ ССЫЛКА (Link) ] ──► (Web / File / Folder / Program / Script)
```

* **Уровень 1: Сфера (Sphere)** — контекст высшего уровня. Сферы полностью изолируют окружения друг от друга. По умолчанию создаются две сферы: **«Работа»** и **«Личное»**. При переключении сферы перестраивается вся структура разделов и категорий.
* **Уровень 2: Раздел (Section)** — крупная тематическая область внутри сферы (например, *«Проекты»*, *«Инфраструктура»*, *«Финансы»*). Разделы отображаются в левом навигационном дереве.
* **Уровень 3: Категория (Category)** — группа ресурсов внутри раздела (например, *«Бэкенд»*, *«Мониторинг»*, *«Документация»*). Категории отображаются в дереве, а при клике на раздел — раскрываются в центральной области в виде наглядных плиток (**Tiles**).
* **Уровень 4: Ссылка (Link)** — непосредственный рабочий объект: интернет-страница, локальный документ, каталог, приложение или скрипт.

## 2. Установка, запуск и системные требования

### Системные требования
* **ОС**: Windows 10 или Windows 11 (64-бит).
* **Свободное место на диске**: ~150 МБ.
* **Экран**: разрешение от 1024×768 (полная поддержка экранов HiDPI).
* **Python (при запуске из исходников)**: Python 3.12 или новее.

### Способы запуска
* **Через инсталлятор**: запустите `AiteCommander-Setup-<версия>.exe`. Мастер установит программу и создаст ярлыки в меню «Пуск» и на рабочем столе.
* **Через пакетный файл**: запустите `aitecommander.bat` в корневом каталоге проекта.
* **Через виртуальное окружение**:
  ```powershell
  .\.venv\Scripts\python.exe -m app.main
  ```

### Параметры командной строки
При запуске из терминала поддерживаются следующие аргументы:

| Флаг | Назначение |
| :--- | :--- |
| `--debug` | Включает режим расширенной отладки с детальным выводом в консоль. |
| `--log-level LEVEL` | Устанавливает уровень журналирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`). |
| `--no-gui` | Запуск без графического интерфейса (для служебных задач). |
| `--version` | Выводит текущую версию программы и завершает работу. |

### 3.1. Главное меню (File, Data, Help)
Главное меню расположено в верхней строке окна и сгруппировано в три логических раздела:

#### Меню «&File» (Файл):
* **Add section (F3)** — вызов диалога создания нового раздела.
* **Add category (F4)** — создание новой категории.
* **Add link (F1)** — добавление новой ссылки в текущую категорию.
* **Search files (F8)** — вызов диалога расширенного поиска файлов на локальных дисках.
* **Settings (F7)** — окно настроек внешнего вида, языка и параметров программы.
* **Exit (Alt+F4)** — корректное завершение работы приложения.

#### Меню «&Data» (Данные):
* **Connect Database (Ctrl+Alt+D)** — подключение внешней базы или импорт структуры.
* **Save Database (Ctrl+Alt+S)** — сохранение/экспорт всей структуры базы в архив.
* **Restore Database (Ctrl+Alt+B)** — восстановление базы из автоматической резервной копии.
* **Import Browser Bookmarks (Ctrl+Alt+C)** — импорт закладок из HTML-файлов браузеров.
* **Check Bad URLs (Ctrl+Alt+U)** — запуск утилиты сканирования и очистки неработающих ссылок.
* **Clear Favorites (Ctrl+Alt+F)** — быстрая очистка списка «Избранное».
* **Import Icons (Ctrl+Alt+I)** — импорт пакета значков из ZIP-архива.
* **Export Icons (Ctrl+Alt+E)** — выгрузка пользовательских иконок в ZIP-архив.
* **Refresh Icons (Ctrl+Alt+H)** — принудительное фоновое обновление фавиконок всех сайтов.

#### Меню «&Help» (Справка):
* **About** — информация о версии Aite Commander, лицензии и разработчиках.

### 3.2. Верхняя панель (Topbar)
Верхняя панель служит центром оперативного доступа:
* **Кнопки быстрого добавления (Quick Add)**: пиктограммы «+ Ссылка», «+ Категория» и «+ Раздел».
* **Панель «Избранное» (Favorites)**: ссылки, отмеченные пользователем звездочкой. Первые 9 ссылок на панели получают горячие клавиши **Alt+1** … **Alt+9**.
* **Панель «Недавние» (Recents)**: автоматически обновляемая лента ресурсов, открывавшихся последними.
* **Строка полнотекстового поиска (Ctrl+F)**: текстовое поле с дебаунсом 300 мс для поиска «на лету» без задержек.

---

### 3.3. Левая навигационная колонка и панель сфер
Левая панель разделена на две части:
* **Дерево структуры (`StructureTreeView`)**: иерархический список разделов и категорий. Поддерживает раскрытие веток стрелками клавиатуры, выбор мышью и Drag & Drop.
* **Панель сфер (`spheres_bar`)**: расположена в самом низу левой колонки (под деревом). Представляет собой ряд крупных кнопок с иконками («Работа», «Личное»). Клик по кнопке активирует выбранную сферу.

---

### 3.4. Центральная рабочая область (Плитки и Таблица)
Центральная область динамически меняет свой вид в зависимости от того, какой элемент выбран в левом дереве:
* **Когда в дереве выбран Раздел**: центральная панель отображает **плиточную сетку категорий (`Category Tiles View`)**. Каждая категория представлена крупной карточкой (размер по умолчанию 128×110 px) с иконкой и подписью. Двойной клик по плитке переносит вас внутрь категории.
* **Когда в дереве выбрана Категория**: центральная панель отображает **содержимое категории (`LinksTableView`)** в виде таблицы со столбцами:
  1. *Избранное (★)* — переключатель статуса ссылки;
  2. *Имя* — название ссылки и иконка типа ресурса;
  3. *Последнее открытие* — дата и время последнего запуска;
  4. *Заметки* — текстовый комментарий к ссылке.
  *Клик по заголовку любого столбца сортирует список.*

### 3.6. Строка состояния (Status Bar)

## 4. Управление структурой: Сферы, Разделы, Категории

### 4.1. Работа со Сферами
Сферы позволяют разделить несвязанные контексты. Например, все закладки для рабочих задач находятся в сфере «Работа», а домашние рецепты, хобби и игры — в сфере «Личное».
* **Как переключить сферу**: нажмите **F6** (или кликните по кнопке сферы внизу левой панели).
* При переключении структура левого дерева полностью заменяется на данные выбранной сферы.

---

### 4.2. Создание и редактирование Разделов (F3)
Раздел служит базовой тематической папкой (например, *«Проекты»*, *«Серверы»*, *«Учеба»*).

1. **Создание**: нажмите **F3** (или кнопку **[F3 Раздел]** на нижней панели).
2. **Диалоговое окно `SectionDialog`**:
   * **Поле «Имя:»** — введите название раздела. Курсор уже установлен в этом поле.
   * **Кнопка «Иконка»** — кликните для открытия каталога иконок и выбора подходящего значка.
   * **Выпадающий список «Сфера:»** — по умолчанию подставлена активная сфера, но при необходимости раздел можно сразу привязать к другой.
3. **Валидация**: программа автоматически проверяет уникальность имени раздела в рамках сферы, исключая появление случайных дубликатов.
4. **Сохранение**: нажмите «Сохранить» (или клавишу Enter). Раздел появится в дереве слева.
5. **Редактирование**: выделите раздел в дереве и нажмите **F2**. В открывшемся окне можно переименовать раздел, изменить значок или переместить его в другую сферу.

---

### 4.3. Создание и редактирование Категорий (F4)
Категория создается внутри конкретного раздела и служит контейнером для ссылок.

1. **Создание**: выделите родительский раздел в левом дереве и нажмите **F4** (или кнопку **[F4 Категория]** на нижней панели).
2. **Диалоговое окно `CategoryDialog`**:
   * **Поле «Имя:»** — название категории (например, *«Бэкенд»*, *«Базы данных»*).
   * **Кнопка «Иконка»** — выбор значка категории.
   * **Списки «Сфера:» и «Раздел:»** — родительский раздел подставляется автоматически из выбранного в дереве. При смене сферы список разделов динамически обновляется.
3. **Сохранение**: нажмите «Сохранить».
4. **Отображение**:
   * Категория появляется в дереве как дочерний узел своего раздела.
   * Если кликнуть по родительскому разделу в дереве, категория отобразится в центре в виде крупной плитки.
5. **Редактирование**: выделите категорию и нажмите **F2** для смены имени, значка или переноса в другой раздел.

---

### 4.4. Удаление элементов и защита данных (Undo / Redo)
* **Удаление (Del)**: выделите любой раздел, категорию или ссылку и нажмите клавишу **Del** (или кнопку **[Del Удалить]**).
  * Перед удалением программа запросит подтверждение.
  * **Каскадное удаление**: при удалении раздела будут удалены все входящие в него категории и ссылки.
* **Отмена ошибочного действия (Undo, Ctrl+Z)**: если вы случайно удалили или переместили элемент, нажмите **Ctrl+Z**. Aite Commander поддерживает полный стек отмены операций со структурой и ссылками — объект мгновенно восстановится на своем месте.
* **Повтор отмененного действия (Redo, Ctrl+Y / Ctrl+Shift+Z)**: восстанавливает действие, отмененное через Undo.

## 5. Работа со ссылками: 5 типов ресурсов

### 5.1. Вызов и устройство диалога ссылки (F1)
Чтобы добавить ссылку:
1. Выберите в дереве нужную категорию (или дважды кликните по плитке категории в центре).
2. Нажмите клавишу **F1** (или кнопку **[F1 Ссылка]** на нижней панели).
3. Откроется окно `LinkDialog`:

```
+-----------------------------------------------------------------------+
|  Тип:  [ (🌐) Web ]  [ (📄) File ]  [ (⚙️) App ]  [ (📜) Script ]  [ (📁) Folder ]  |
+-----------------------------------------------------------------------+
|  URL / Путь: [ https://gitlab.company.com             ] [ Обзор / Профиль ] |
|  Имя:        [ Корпоративный GitLab                   ] [ Выбрать иконку ] |
|  Аргументы:  [ Как приложение (--app={url}) v         ]                   |
|  Сфера:      [ Работа v ]  Раздел: [ Проекты v ]  Категория: [ CI/CD v ] |
|  Заметки:    [ Доступ через корпоративный VPN...                         ] |
|  [x] Добавить в избранное                                             |
|                                         [ Сохранить ]  [ Отмена ]     |
+-----------------------------------------------------------------------+
```

Форма диалога адаптивна: в зависимости от выбранного переключателя типа ссылки в верхней части окна меняется назначение полей и кнопок.

---

### 5.2. Веб-ссылка (Web link): фавиконы, пресеты аргументов, профили браузеров
* **Назначение**: сайты, веб-сервисы, облачные панели.
* **Поле «URL/Path:»**: вставьте интернет-адрес (например, `https://github.com`).
* **Автоматическое получение фавиконки**: как только URL введен, программа в фоновом режиме связывается с веб-сайтом, скачивает его официальную иконку высокого разрешения и отображает на кнопке значка.
* **Пресеты аргументов запуска**:
  * *«По умолчанию»* — обычное открытие ссылки во вкладке браузера по умолчанию.
  * *«Как приложение» (`--app={url}`)* — **рекомендуемый режим для веб-сервисов!** Сайт запускается в изолированном окне без адресной строки, тулбаров и вкладок, функционируя как полноценная десктопная программа.
  * *«Инкогнито» (`--incognito`)* — открытие в приватном режиме без кэша и сохранения авторизации.
  * *«Новое окно» (`--new-window`)*.
  * *«Гостевой режим» (`--guest`)*.
* **Выбор профиля браузера**: кнопка **«Профиль»** позволяет закрепить ссылку за определенным браузером или профилем пользователя (поддерживаются Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Vivaldi, Opera, Яндекс Браузер).

---

### 5.3. Локальный файл (File)
* **Назначение**: рабочие документы Word (`.docx`), таблицы Excel (`.xlsx`), PDF-инструкции, презентации, конфигурационные файлы.
* **Как настроить**: выберите тип `File`, нажмите кнопку **«Обзор...» (Browse...)** и укажите файл на диске. Программа автоматически подставит путь и заполнит имя файла.
* **Как запускается**: при клике или нажатии Enter файл открывается в стандартном приложении Windows, ассоциированном с данным расширением.

---

### 5.4. Папка (Folder)
* **Назначение**: локальные директории проектов, папки загрузок, сетевые диски и UNC-пути (`\\server\shared`).
* **Как настроить**: выберите тип `Folder`, через кнопку «Обзор...» укажите каталог.
* **Как запускается**: моментально открывается Проводник Windows (Explorer) с переходом в эту папку.

---

### 5.5. Программа (Application) и ярлыки (.lnk)
* **Назначение**: исполняемые файлы программ (`.exe`) и ярлыки рабочего стола (`.lnk`).
* **Как настроить**: выберите тип `Application`, укажите путь к файлу. Если выбран ярлык `.lnk`, программа извлечет из него исходные аргументы и значок.
* **Аргументы запуска**: поле «Аргументы» превращается в текстовую строку, куда можно ввести любые ключи командной строки (например, `--no-sandbox --profile "User1"`).

---

### 5.6. Скрипт автоматизации (Script)
* **Назначение**: командные сценарии автоматизации (`.bat`, `.cmd`, `.ps1`, `.py`, `.vbs`, `.sh`).
* **Как настроить**: выберите тип `Script`, укажите путь к сценарию и параметры запуска в поле аргументов. Скрипт будет выполняться в контексте своей рабочей директории.

---

### 5.7. Ведение заметок (NoteDialog, Ctrl+N)
К каждой ссылке можно прикрепить произвольный текст заметок:
* Заметки можно заполнить в поле «Заметки:» при создании ссылки.
* Чтобы быстро просмотреть или отредактировать заметки существующей ссылки, выделите ее и нажмите **Ctrl+N** (или кликните правой кнопкой мыши → *«Заметки»*). Откроется окно `NoteDialog`.
* Наличие заметки обозначается в таблице ссылок в колонке «Заметки».

---

### 5.8. Панель «Избранное» и быстрый запуск (Alt+1..9)
* Чтобы добавить ссылку в «Избранное», выделите ее и нажмите **Ctrl+D** (или поставьте галочку при редактировании).
* Ссылка появится на верхней панели быстрого доступа.
* Первые 9 ссылок в Избранном получают автоматические шорткаты: **Alt+1**, **Alt+2**, …, **Alt+9**. Нажатие соответствующего сочетания открывает ссылку из любой части программы без мыши.

---

### 5.9. Социальный шаринг и экспорт ссылок
Кликните правой кнопкой мыши по любой ссылке и выберите подменю **«Поделиться»**:
* **Мессенджеры и сети**: мгновенная отправка ссылки в Telegram, WhatsApp, X (Twitter), LinkedIn, Facebook, Pinterest, Viber.
* **Электронная почта**: создание черновика письма в Gmail или системном почтовом клиенте (mailto:) с подставленным заголовком и адресом.
* **Буфер обмена**: быстрое копирование форматированного адреса.

---

### 5.10. Пакетные операции и Drag & Drop
* **Множественное выделение**: зажмите клавишу `Shift` или `Ctrl` для выделения нескольких строк в таблице ссылок.
* **Пакетное удаление**: выделите несколько элементов и нажмите `Del` — все выбранные ссылки удалятся за одну операцию.
* **Drag & Drop ссылок**: выделите одну или несколько ссылок, зажмите левую кнопку мыши и перетащите их на любую категорию в левом дереве структуры для быстрого перемещения.
* **Drag & Drop из Проводника Windows**: перетащите файл или папку прямо из Проводника Windows в окно Aite Commander — программа автоматически откроет диалог добавления с предзаполненным путем.

---

## 6. Инструменты поиска

### 6.1. Мгновенный полнотекстовый поиск (Ctrl+F)
1. Нажмите **Ctrl+F** в любой момент работы.
2. Фокус переместится в строку поиска в правом верхнем углу.
3. Введите фрагмент названия, адреса, аргументов или текста заметок.
4. Таблица мгновенно отфильтруется (поиск снабжен защитой от дребезга ввода — дебаунс 300 мс).
5. Выберите нужную строку стрелками клавиатуры и нажмите **Enter** для запуска.
6. Нажмите **Escape** для сброса поисковой строки и возврата к полному списку.

---

### 6.2. Расширенный поиск файлов на диске (F8)
Встроенный диалог поиска файлов `FileSearchDialog` позволяет находить документы и программы на диске и сразу добавлять их в базу Aite Commander:

1. Нажмите клавишу **F8** (или выберите меню *File → Search files*).
2. **Параметры поиска**:
   * **«Search files:»** — имя файла или регулярное выражение (например, `*.pdf`, `budget_2026.*`).
   * **«Search in:»** — директория поиска (диск `C:\`, папка `D:\Docs` и т.д.).
   * **«Content:»** — поиск по внутреннему тексту документов с выбором кодировки (UTF-8, Windows-1251).
   * **Группа «Advanced»**: ограничение глубины сканирования (`Max depth`), фильтрация по расширениям (`Allowed exts`) и размеру (`Max size`).
3. Нажмите кнопку **«Search»** для старта фонового сканирования.
4. В таблице результатов выделите найденные файлы и нажмите кнопку добавления, чтобы превратить их в ссылки выбранной категории Aite Commander.

## 7. Импорт, экспорт и обмен данными

### 7.1. Импорт закладок из браузеров (Ctrl+Alt+C)
Позволяет без потерь перенести базу ссылок из Chrome, Edge, Firefox, Brave, Opera, Vivaldi или Яндекс Браузера:

1. В вашем браузере перейдите в диспетчер закладок (`Ctrl+Shift+O`) и экспортируйте закладки в HTML-файл.
2. В Aite Commander нажмите **Ctrl+Alt+C** (или меню *Data → Import Browser Bookmarks*).
3. В появившемся диалоге выберите целевую сферу и раздел, куда требуется поместить импортированные данные.
4. Укажите HTML-файл закладок.
5. Программа распарсит структуру, автоматически создаст разделы и категории, извлечет сохраненные значки и нормализует URL.

---

### 7.2. Полный и частичный экспорт/импорт структуры в ZIP (Ctrl+Alt+S / Ctrl+Alt+D)
* **Полный экспорт базы (Ctrl+Alt+S)**: меню *Data → Save Database* сохраняет всю базу данных (все сферы, разделы, категории, ссылки, заметки и значки) в компактный переносимый архив ZIP.
* **Импорт базы (Ctrl+Alt+D)**: меню *Data → Connect Database* позволяет загрузить архив на новом компьютере с полным восстановлением структуры.
* **Частичный экспорт**: кликните правой кнопкой мыши по отдельному разделу или категории в левом дереве → выберите *«Экспорт»*. Созданный ZIP-пакет содержит только выбранную ветку и может быть передан коллеге.

---

### 7.3. Экспорт и импорт архива иконок (Ctrl+Alt+E / Ctrl+Alt+I)
* **Ctrl+Alt+E** (Export Icons) — упаковывает все накопленные в программе значки в ZIP-архив.
* **Ctrl+Alt+I** (Import Icons) — импортирует значки из ранее сохраненного архива в локальную коллекцию.

---

## 8. Обслуживание базы данных и безопасность

### 8.1. Хранение данных SQLite и WAL-режим
Aite Commander хранит данные в локальной реляционной базе данных SQLite:
* **Файл базы**: `%APPDATA%\Codebdbd\Aite Commander\links.db`
* **Режим WAL (Write-Ahead Logging)**: обеспечивает параллельный доступ на чтение и запись без блокировок и предотвращает повреждение базы при аварийном завершении работы системы.
* **Memory-mapped I/O**: размер кэша 256 МБ обеспечивает мгновенный отклик даже на базах с тысячами ссылок.

---

### 8.2. Автоматические бэкапы и восстановление (Ctrl+Alt+B)
При каждом запуске и изменении данных программа автоматически создает резервную копию в папке:
`%APPDATA%\Codebdbd\Aite Commander\backups\`

#### Как восстановить базу:
1. Нажмите **Ctrl+Alt+B** (или меню *Data → Restore Database*).
2. В диалоге `RestoreDbDialog` появится таблица всех доступных точек восстановления с указанием даты, точного времени и размера файла.
3. Выделите нужную резервную копию и нажмите **«Restore»**. Программа проверит целостность файла и откатит базу к выбранной точке.

---

### 8.3. Проверка доступности URL (Bad URL Checker, Ctrl+Alt+U)
1. Нажмите **Ctrl+Alt+U** (или меню *Data → Check Bad URLs*).
2. Откроется окно `BadUrlCleanupDialog`, и многопоточный воркер начнет параллельную проверку всех веб-ссылок в базе данных на:
   * Ошибки разрешения доменных имен (DNS failures);
   * Ошибки рукопожатия SSL-сертификатов;
   * Ошибки HTTP (404 Not Found, 500 Server Error, таймауты подключения).
3. Список недоступных ссылок отображается в итоговой таблице. Вы можете выделить ненужные строки и нажать **«Удалить выбранные»** для пакетной очистки базы от «мертвых» ссылок.

---

### 8.4. Принудительное обновление кэша иконок (Ctrl+Alt+H)
Если сайт сменил свой логотип или значок временно отображается пустым, нажмите **Ctrl+Alt+H** (меню *Data → Refresh Icons*). Программа запустит фоновый пул потоков для принудительного повторного скачивания фавиконок всех добавленных веб-ресурсов.

---

## 9. Настройки программы и персонализация (F7)

### 9.1. Диалог настроек: язык, темы, шрифты, лимиты бэкапов
Нажмите клавишу **F7** (или меню *File → Settings*) для открытия окна `SettingsDialog`:

* **Язык интерфейса (Language)**:
  * Поддерживаются: Русский, English, Українська, Deutsch, Français, Español.
  * Язык переключается мгновенно на лету без необходимости перезапуска программы.
* **Тема оформления (Theme)**:
  * В программу встроено **16 готовых тем оформления**:
    * **Тёмные**: `Dark` (классическая тёмная), `Matrix` (зелёный ретро-терминал), `Violet Pulse` (неоновый фиолетовый), `Crimson Noir` (чёрно-красный контраст), `Cyberpunk Neon` (яркий киберпанк), `Ghost Terminal` (монохромный терминал), `Industrial Yellow` (графитово-жёлтый стиль), `Obsidian Luxe` (глубокий обсидиановый), `Rasta Royale` (насыщенный триколор).
    * **Светлые и пастельные**: `Light` (классическая светлая), `Love` (тёплая розовая гамма), `Nord Light` (скандинавская холодная), `Pastel Bloom` (весенняя пастель), `Pearl Gray` (нейтральная жемчужно-серая), `Sage Light` (спокойный шалфейно-зелёный), `Sakura Anime` (нежная розовая сакура).
* **Размер шрифта (Font size)**: выбор базового кегля интерфейса от 9 до 14 pt (позволяет настроить комфортный масштаб на экранах любого разрешения).
* **Максимум резервных копий (Max backups)**: настройка глубины хранения автобэкапов (от 1 до 10 файлов).

---

### 9.2. Установка пользовательских тем оформления
Aite Commander поддерживает подключение сторонних тем оформления через `.zip`-пакеты:
1. В окне настроек (**F7**) нажмите кнопку **«Импортировать тему»**.
2. Укажите `.zip`-архив темы. Пакет темы должен содержать файл манифеста `theme.json`, стили `qss/` и иконки `icons/`.
3. Установленная тема появится в общем списке тем и сохранится в каталоге:
   `%APPDATA%\Codebdbd\Aite Commander\themes\`

---

### 9.3. Конфигурационные файлы settings.ini и settings.json
* **`settings.ini`** (`%APPDATA%\Codebdbd\Aite Commander\settings.ini`) — хранит пользовательские параметры интерфейса: активную тему, кегль шрифта, геометрию окон, пользовательские привязки горячих клавиш.
* **`settings.json`** — определяет системные лимиты (размеры кэша, задержки дебаунса, таймауты сетевых запросов).

## 11. Диагностика и решение проблем (FAQ & Troubleshooting)

### 1. Фавиконка сайта не загрузилась или осталась стандартной
* **Причина**: Сайт блокирует запросы к `favicon.ico`, требует специфических User-Agent заголовков либо использует динамические SVG-иконки.
* **Решение**: Нажмите **Ctrl+Alt+H** для принудительного повторного скачивания. Либо выделите ссылку, нажмите **F2**, кликните по кнопке «Иконка» и выберите значок вручную из каталога значков или локального файла.

### 2. При запуске файла или скрипта система сообщает «Файл не найден»
* **Причина**: Файл был перемещен, диск отключен, либо в пути с пробелами отсутствуют кавычки.
* **Решение**: Нажмите **F2** на ссылке, нажмите «Обзор...» и заново укажите файл. Если путь или аргументы содержат пробелы, обязательно обрамляйте их в двойные кавычки (например: `"--config" "C:\My Folder\config.json"`).

### 3. Как перенести всю рабочую среду Aite Commander на новый ПК
1. На старом компьютере нажмите **Ctrl+Alt+S** и сохраните архив экспорта.
2. Установите Aite Commander на новом компьютере.
3. Нажмите **Ctrl+Alt+D**, укажите сохраненный ZIP-архив и подтвердите импорт. Все сферы, разделы, категории, ссылки, параметры запуска, заметки и значки будут развернуты в исходном виде.

### 4. Где найти лог-файлы приложения при сбоях?
Файлы журналов приложения находятся в подкаталоге:
`%APPDATA%\Codebdbd\Aite Commander\logs\app.log`

Для детальной диагностики через командную строку запустите программу с ключами отладки:
```powershell
python -m app.main --debug --log-level DEBUG
```
В терминал будет выводиться подробная трассировка запросов к базе данных, фоновых воркеров и событий графического интерфейса.

### 5. Как сбросить настройки интерфейса, не потеряв базу данных?
1. Полностью закройте Aite Commander (**Alt+F4**).
2. Нажмите сочетание клавиш `Win + R`, введите `%APPDATA%\Codebdbd\Aite Commander\` и нажмите Enter.
3. Удалите файл `settings.ini`.
4. Запустите программу. Настройки геометрии окон, шрифтов и тем вернутся к значениям по умолчанию, а база данных `links.db` останется полностью в сохранности.
