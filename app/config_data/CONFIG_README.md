# Документация конфигурации приложения

Этот файл содержит описание всех параметров конфигурации из `app_config.json`.

## UI Параметры

### Кнопки быстрого доступа (верхняя панель)
- **`ui.quick_button_size`** (32) - размер квадратных кнопок быстрого доступа в пикселях
- **`ui.top_panel_icon_size`** (32) - размер иконок в верхней панели

### Кнопки сфер (круглые категории)
- **`ui.sphere_button_icon_size`** (48) - размер иконок в круглых кнопках сфер в пикселях

### Плитки категорий (квадратные элементы в центре)
- **`ui.tile_icon_size`** [48, 48] - размер иконки внутри плитки [ширина, высота] в пикселях
- **`ui.tile_width`** (110) - ширина одной плитки категории в пикселях
- **`ui.tile_height`** (110) - высота одной плитки категории в пикселях
- **`ui.tile_spacing`** (12) - расстояние между плитками в пикселях
- **`ui.tile_padding`** (10) - внутренний отступ от края плитки до содержимого в пикселях
- **`ui.tile_icon_text_gap`** (5) - расстояние между иконкой и текстом в плитке в пикселях
- **`ui.tile_text_font_size`** (10) - размер шрифта для названия категории в пунктах
- **`ui.tile_text_max_lines`** (4) - максимальное количество строк текста в плитке
- **`ui.tile_border_radius`** (8) - радиус закругления углов плитки в пикселях
- **`ui.tile_border_width`** (2) - толщина границы плитки в пикселях
- **`ui.tile_border_margin`** (2) - отступ границы от содержимого в пикселях

### Панели и общие элементы
- **`ui.spheres_bar_height`** (64) - высота панели с круглыми кнопками сфер в пикселях
- **`ui.default_font_size`** (12) - базовый размер шрифта для всего приложения в пунктах
- **`ui.search_placeholder`** "Поиск… (Ctrl+F)" - текст-подсказка в строке поиска
- **`ui.central_frame_shape`** "StyledPanel" - стиль центральной области
- **`ui.default_icon_size`** (24) - размер иконок по умолчанию для всего приложения в пикселях

### Дерево разделов
- **`ui.tree_icon_size`** [28, 28] - размер иконок в дереве разделов [ширина, высота] в пикселях
- **`ui.tree_spacing`** (2) - расстояние между элементами в дереве в пикселях

### Кнопки панелей
- **`ui.panel_button_size`** (32) - размер кнопок в боковых панелях в пикселях
- **`ui.panel_button_spacing`** (5) - расстояние между кнопками в панели в пикселях

## Параметры путей
- **`paths.icons_cache`** - путь к кэшу иконок
- **`paths.icons_custom`** - путь к пользовательским иконкам
- **`paths.icons_default`** - путь к стандартным иконкам

## Параметры лимитов
- **`limits.max_links_per_category`** (1000) - максимальное количество ссылок в одной категории
- **`limits.max_categories`** (100) - максимальное количество категорий
- **`limits.max_favorites`** (20) - максимальное количество избранных элементов

## Параметры настроек
- **`settings.auto_save_interval`** (5000) - интервал автосохранения в миллисекундах
- **`settings.backup_count`** (5) - количество резервных копий
- **`settings.theme`** "auto" - тема оформления (auto/light/dark)

## Как изменять параметры

1. Откройте файл `app_config.json`
2. Найдите нужный параметр
3. Измените значение
4. Сохраните файл
5. Перезапустите приложение

### Примеры изменений:

**Увеличить иконки в плитках:**
```json
"tile_icon_size": [64, 64]
```

**Увеличить размер плиток:**
```json
"tile_width": 150,
"tile_height": 150
```

**Изменить расстояние между плитками:**
```json
"tile_spacing": 20
```

**Изменить размер шрифта в плитках:**
```json
"tile_text_font_size": 14
```

## Примечания

- Все размеры указываются в пикселях
- Размеры шрифтов указываются в пунктах
- Изменения вступают в силу после перезапуска приложения
- Некоторые параметры требуют перезапуска для применения
