# Полная интернационализация (i18n) для Aite Commander

## Обзор

Проект **Aite Commander** теперь полностью поддерживает интернационализацию с использованием Qt Linguist. Система позволяет переключать язык интерфейса без перезапуска приложения и поддерживает 6 языков.

## Поддерживаемые языки

- **en** (English) - английский (исходный язык)
- **uk** (Українська) - украинский
- **ru** (Русский) - русский
- **fr** (Français) - французский
- **es** (Español) - испанский
- **de** (Deutsch) - немецкий

## Архитектура

### Ключевые компоненты

#### 1. LanguageService (`i18n/language_service.py`)
Центральный сервис управления языками:
- Singleton паттерн
- Автоматическое определение системного языка
- Сохранение выбранного языка в QSettings
- Загрузка/выгрузка переводчиков
- Сигналы изменения языка для обновления UI

#### 2. Locale Utils (`i18n/locale_utils.py`)
Утилиты для локализованного форматирования:
- `format_datetime()` - форматирование дат
- `format_decimal()` - форматирование чисел
- `format_currency()` - форматирование валюты
- `format_filesize()` - форматирование размеров файлов

#### 3. ReTranslatable Mixin (`app/views/common/retranslatable.py`)
Автоматическое обновление UI при смене языка:
- Подключение к сигналам LanguageService
- Автоматический вызов `retranslateUi()` при смене языка
- Безопасное отключение при уничтожении виджета

#### 4. LanguageSelector (`app/views/widgets/language_selector.py`)
UI компонент для выбора языка:
- ComboBox с доступными языками
- Автоматическое обновление при смене языка
- Сохранение выбора в настройках

## Файлы переводов

### Структура файлов

```
i18n/
├── app_en.ts    # Английский (исходный)
├── app_uk.ts    # Украинский
├── app_ru.ts    # Русский
├── app_fr.ts    # Французский
├── app_es.ts    # Испанский
└── app_de.ts    # Немецкий
```

### Компиляция переводов

После редактирования `.ts` файлов в Qt Linguist:

```bash
# Компиляция всех переводов
lrelease i18n/*.ts

# Или через скрипт
scripts\i18n_build.bat
```

## Использование в коде

### В классах QObject

```python
class MyWidget(QWidget):
    def retranslateUi(self):
        self.setWindowTitle(self.tr("My Window"))
        self.button.setText(self.tr("Click me"))
        self.label.setToolTip(self.tr("Help text"))
```

### Вне классов QObject

```python
from PyQt6.QtCore import QCoreApplication

def show_message():
    title = QCoreApplication.translate("Context", "Message Title")
    text = QCoreApplication.translate("Context", "Message text")
    QMessageBox.information(None, title, text)
```

### Плюрализация

```python
# В классах QObject
count_text = self.tr("%n file(s)", None, count)

# Вне классов QObject
count_text = QCoreApplication.translate("Context", "%n file(s)", None, count)
```

## Рабочий процесс разработки

### 1. Добавление новых строк

При добавлении пользовательских строк в код:

```python
# Вместо жестко закодированных строк
self.label.setText("Hello World")

# Использовать переводы
self.label.setText(self.tr("Hello World"))
```

### 2. Экстракция строк

```bash
# Экстракция всех переводимых строк
scripts\i18n_extract.bat
```

### 3. Редактирование переводов

1. Открыть `.ts` файлы в **Qt Linguist**
2. Перевести строки на целевые языки
3. Сохранить файлы

### 4. Компиляция

```bash
# Компиляция переводов
scripts\i18n_build.bat
```

### 5. Тестирование

1. Запустить приложение
2. Изменить язык через меню Настройки → Language
3. Проверить, что интерфейс обновился

## Интеграция с PyInstaller

Файлы переводов автоматически включаются в сборку через `.spec` файл:

```python
# В .spec файле
datas=[
    ('i18n/*.qm', 'i18n'),
]
```

## Технические детали

### Автозагрузка переводов

Переводчики загружаются автоматически при старте приложения в порядке:
1. Определение системного языка
2. Загрузка сохраненного языка из настроек
3. Загрузка соответствующих `.qm` файлов
4. Установка переводчиков в QApplication

### Обновление UI

При смене языка:
1. LanguageService выгружает старые переводчики
2. Загружает новые переводчики
3. Испускает сигнал `languageChanged`
4. Все виджеты с ReTranslatable автоматически вызывают `retranslateUi()`

### Производительность

- Переводчики загружаются только один раз при смене языка
- Кэширование переводов в памяти
- Асинхронное обновление UI не блокирует интерфейс
