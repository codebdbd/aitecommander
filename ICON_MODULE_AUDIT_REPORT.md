## ИСПРАВЛЕННЫЕ ПРОБЛЕМЫ

### 🔴 Критичные (все исправлены)

#### 1. ✅ Отсутствовал модуль `app.utils.locking`

**Проблема:** `lock_manager.py:14-23` импортировал несуществующий модуль, все блокировки не работали.

**Исправление:**
- Создан `app/utils/locking.py` (180 строк)
- Реализованы именованные RLock для icon подсистемы
- Добавлена защита от deadlock через автоматическую сортировку блокировок
- Реализованы утилиты для отладки (`get_lock_info`, `reset_all_locks`)

**Файлы:**
- `app/utils/locking.py` — новый модуль

---

#### 2. ✅ Создание QIcon вне GUI-потока

**Проблема:** 3 места создавали QIcon в фоновых потоках, что приводит к крэшам Qt.

**Исправления:**

**2.1. `selection.py:38`**
- Добавлена проверка GUI-потока в начале функции
- `RuntimeError` если вызвано из фонового потока
- Файл: `app/utils/ui/icon/selection.py:25-28`

**2.2. `cache_manager.py:783`**
- Добавлена проверка GUI-потока
- Возврат пустой иконки с warning если вызвано из фонового потока
- Файл: `app/utils/ui/icon/cache_manager.py:782-792`

**2.3. `creators.py:543`**
- Переписана логика `create_icon_from_path_async`
- I/O операции в executor, создание QIcon через `run_in_gui_thread_async`
- Файл: `app/utils/ui/icon/icon_operations/creators.py:504-550`

---

#### 3. ✅ Некорректная синхронизация в `gui_exec.py`

**Проблема:** Использовался `asyncio.Event` в синхронном контексте, блокировал event loop.

**Исправление:**
- Заменён `asyncio.Event` на `threading.Event`
- Убран `loop.run_until_complete()` который блокировал GUI
- Добавлена документация о причинах изменения
- Файл: `app/utils/ui/qt/gui_exec.py:36-69`

---

### ⚠️ Средние (все исправлены)

#### 4. ✅ Утечка памяти в `negative_cache._strikes`

**Проблема:** Словарь `_strikes` рос бесконечно, ключи не удалялись при истечении TTL.

**Исправление:**
- При истечении TTL: strikes уменьшаются, при достижении 0 — ключ удаляется
- При вытеснении по размеру: strikes удаляются полностью
- Файлы: `app/utils/ui/icon/negative_cache.py:143-148, 168-172, 195-196`

---

#### 5. ✅ Отсутствие тестов

**Проблема:** Модуль не покрыт тестами, невозможно проверить потокобезопасность.

**Исправление:**
Созданы 3 файла тестов (всего ~450 строк):

1. **`tests/test_icon_thread_safety.py`** (200 строк)
   - Проверка создания QIcon только в GUI-потоке
   - Тесты async функций
   - Проверка защиты от вызовов из фоновых потоков

2. **`tests/test_icon_negative_cache.py`** (200 строк)
   - Экспоненциальный TTL
   - Отсутствие утечек памяти в `_strikes`
   - Корректность очистки при invalidate

3. **`tests/test_locking.py`** (180 строк)
   - Работа блокировок
   - Предотвращение deadlock
   - Реентерабельность RLock
   - Стресс-тесты с 50+ потоками

    └── ui_helpers.py (28 строк) — утилиты для виджетов

### Ключевые особенности

✅ **Многоуровневое кэширование:**
- LRU кэш с настраиваемым размером
- TTL для обычных и absolute path иконок
- Negative cache с экспоненциальным TTL (60s → 120s → 240s...)
- Интеграция с Qt QPixmapCache

✅ **Производительность:**
- Индексирование иконок по темам (избегает сканирования директорий)
- Fast path для стандартных размеров (16, 24, 32, 48, 64, 128)
- In-flight deduplication (предотвращает дублирование загрузок)
- Lazy loading блокировок

✅ **Потокобезопасность:**
- Централизованные RLock через `app.utils.locking`
- Автоматическая сортировка блокировок (предотвращение deadlock)
- Проверка GUI-потока перед созданием QIcon
- Async операции через `run_in_gui_thread_async`

✅ **Валидация:**
- SVG/SVGZ структурная проверка (не просто расширение)
- PIL.verify() для растровых форматов
- Защита от path traversal
- Проверка размера файлов
