## 🛠️ ИНСТРУМЕНТЫ ДЛЯ РАБОТЫ

### Новые скрипты (созданы при аудите)

1. **`validate_translations.py`** - Валидация .ts файлов
   ```bash
   python i18n/validate_translations.py        # Проверка
   python i18n/validate_translations.py --fix  # Авто-исправление
   ```

2. **`fix_critical_issues.py`** - Быстрое исправление критических проблем
   ```bash
   python i18n/fix_critical_issues.py
   ```

### Существующие инструменты

3. **`update_and_report.py`** - Обновление и отчёты
   ```bash
   python i18n/update_and_report.py --update   # Обновить .ts
   python i18n/update_and_report.py --compile  # Скомпилировать .qm
   python i18n/update_and_report.py --report   # Показать статистику
   python i18n/update_and_report.py --all      # Всё вместе
   ```

4. **`auto_translate.py`** - Автоперевод (осторожно, может создавать баги!)
   ```bash
   python i18n/auto_translate.py --lang uk i18n/app_uk.ts
   ```
