# Исправление системы иконок: убрать default.ico, типовые фоллбэки

## Проблема

После удаления `default.ico` из конфига система иконок сломалась — в интерфейсе дыры вместо иконок. Каждый тип (web, file, folder, section, category) имеет свой дефолт в конфиге. `default.ico` не нужен.

## Корневые причины (4 бага)

### Баг 1: `get_default_icon_path()` возвращает None → все фоллбэки мертвы
**Файл:** `app/utils/ui/icon/icon_resolver.py:15-28`

Функция ищет ключ `"default"` в конфиге — его нет → возвращает `None`. `_safe_default_icon_path()` (строки 9-12) тоже возвращает `""`. Это ломает **8+ мест** где вызывается `_safe_default_icon_path()` и step 4 в `resolve_icon_path()` (строка 89-93 — `candidate.exists()` на None вызывает AttributeError, который молча глотается).

### Баг 2: Negative cache в `icon_resolver.py` блокирует повторную проверку диска
**Файл:** `app/utils/ui/icon/icon_resolver.py:43-50`

При negative cache хите → `get_default_icon_path()` (None) → `return ""`. Файл **никогда не перепроверяется с диска**. Отравление происходит на строке 95-96 (`mark_negative()`), когда step 4 молча проглатывает ошибку.

### Баг 3: `set_snapshot()` не вызывает `resolve_section_icon_path()` при пустом icon_path
**Файл:** `app/views/models/structure_tree_model.py:1037`

```python
resolved_section_path = resolve_section_icon_path(raw_icon_path) if raw_icon_path else ""
```

Если `raw_icon_path = ""` → резолвер не вызывается → `section.png` не применяется. Сам `resolve_section_icon_path("")` работает корректно — он пропускает блок `if icon_path:` и сразу идёт в fallback на `section.png`.

### Баг 4: `set_snapshot()` не вызывает `resolve_category_icon_path()` для категорий
**Файл:** `app/views/models/structure_tree_model.py:1087-1089`

Категории передают сырой `c.get("icon_path")` в `_prepare_icon_fields()` без вызова `resolve_category_icon_path()`. Типовой дефолт `category.png` не применяется.

## План исправления

### Шаг 1: Убрать `default.ico` из хардкода в settings_config.py
**Файл:** `app/config_data/settings_config.py:158`

Удалить строку `"default": "default.ico",`.

### Шаг 2: Переписать `get_default_icon_path()` — type-specific ultimate fallback
**Файл:** `app/utils/ui/icon/icon_resolver.py:15-28`

Вместо поиска ключа `"default"` — перебрать все type-specific иконки из конфига и вернуть первый существующий файл:

```python
def get_default_icon_path() -> Path | None:
    """Return first available type-specific icon as ultimate fallback."""
    try:
        from app.config_data import app_config
        ui_dir = icon_path_service.get_ui_icons_dir()
        for name in app_config.get_default_icons().values():
            if not name:
                continue
            candidate = ui_dir / name
            if candidate.exists() and is_valid_icon_file(str(candidate)):
                return candidate
    except Exception:
        pass
    return None
```

### Шаг 3: Убрать negative cache short-circuit из `icon_resolver.py`
**Файл:** `app/utils/ui/icon/icon_resolver.py:43-50`

Удалить блок проверки negative cache. `path_service.py` уже имеет свой negative cache. Дублирование в `icon_resolver.py` только ломает каскад.

```python
# УДАЛИТЬ строки 43-50:
if negative_key and negative_cache.is_negative(negative_key):
    try:
        candidate = get_default_icon_path()
        if candidate and candidate.exists() and is_valid_icon_file(str(candidate)):
            return str(candidate)
    except Exception:
        pass
    return ""
```

Также удалить `mark_negative(negative_key)` на строке 95-96 (и импорт `mark_negative` на строке 4).

### Шаг 4: Исправить `set_snapshot()` — всегда вызывать типовые резолверы
**Файл:** `app/views/models/structure_tree_model.py`

Строка 1037 — убрать условие `if raw_icon_path`:
```python
# БЫЛО:
resolved_section_path = resolve_section_icon_path(raw_icon_path) if raw_icon_path else ""
# СТАЛО:
resolved_section_path = resolve_section_icon_path(raw_icon_path)
```

Строки 1087-1089 — добавить вызов `resolve_category_icon_path()`:
```python
# БЫЛО:
category_icon, pending_cat_path, stored_cat_path = self._prepare_icon_fields(
    c.get("icon"),
    c.get("icon_path"),
)
# СТАЛО:
category_icon, pending_cat_path, stored_cat_path = self._prepare_icon_fields(
    c.get("icon"),
    resolve_category_icon_path(c.get("icon_path") or ""),
)
```

### Шаг 5: Убрать default.ico файл и QRC запись
- Удалить `app/resources/ui_icons/default.ico`
- Удалить `<file>ui_icons/default.ico</file>` из `app/resources/app_resources.qrc`

### Шаг 6: Почистить устаревшие скрипты
- Удалить `scripts/remove_default_ico.py`
- Удалить `scripts/verify_migration.py`
